### Тема: ОТЛАДКА ПРОГРАММЫ РАЗЛИЧНЫМИ СПОСОБАМИ

*Цель работы:* произвести процедуру отладки программного обеспечения встроенными средствами среды программирования Microsoft Visual Studio.

*Предметная область:* ROT13 — частный случай шифра Цезаря со сдвигом на 13 позиций. Алгоритм является самодвойственным: повторное применение шифра возвращает исходный текст. Обрабатываются только символы латинского алфавита (A-Z, a-z), регистр сохраняется. Цифры, пробелы, знаки препинания и кириллица игнорируются.

- ## Баг-репорты
| ID | Обнаруженный баг | Причина | Решение |
|---|---|---|---|
| `BUG-01` | Кнопка "Дешифровать" не реагирует на нажатие, поле вывода не обновляется. | В `Page1.xaml` указан `Click="BtnDecrypt_Click"`, а среда автоматически создала метод `BtnDecrypt_Click_1` в `Page1.xaml.cs`. Из-за несовпадения имён привязка события разорвалась. | Метод переименован, удален повторный, выполнена полная пересборка решения. |
| `BUG-02` | Тест на самодвойственность (TC_FUN_3) показывает расхождение при автоматическом копировании результата. | Свойство `AcceptsReturn="True"` в `TextBox` захватывает невидимые символы переноса строки (`\r\n`) при выделении `Ctrl+A`, что изменяет длину и содержимое строки при повторном шифровании. | В обработчики добавлен метод `.Trim()` для очистки ввода от пробелов и символов переноса. В журнале ручного тестирования зафиксировано корректное поведение при аккуратном копировании без скрытых символов. |
