### Тема: Создание автоматизированных Unit-тестов

*Цель работы:* провести тестирование разработанных программных модулей с использованием средств автоматизации Microsoft Visual Studio методом "белого ящика".

Порядок выполнения работы:
- Создала консольный проект Bank, добавила класс BankAccount из методички, запустила и проверила работу.
- Создала проект тестов BankTests, добавила ссылку на Bank.
- Написала и отладила тесты для метода Debit, нашла и исправила ошибку в коде.
- Написала аналогичные тесты для метода Credit.
- Запустила все тесты в Обозревателе тестов — все прошли успешно.
- Добавила XML-документацию ко всем публичным членам класса.
- Оформила README.md.

#### Методы:
Debit(double amount) — выполняет списание средств

Credit(double amount) — выполняет пополнение счета
